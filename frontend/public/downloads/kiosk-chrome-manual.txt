Fulfillment CRM — Chrome autoprint (без скачивания скриптов)
============================================================

ВАЖНО: --kiosk-printing — это ТИХАЯ печать без Enter, НЕ полноэкранный режим.
Chrome может быть с вкладками — но через ярлык должна открыться ТОЛЬКО CRM.

Если открылись github / WB / старые вкладки — Chrome проигнорировал флаги ярлыка.
Причина: тот же профиль Chrome. Нужен отдельный профиль (строка ниже).

1. Xprinter — принтер по умолчанию в Windows (58×40 мм).

2. Диспетчер задач → завершить ВСЕ процессы chrome.exe.

3. ПКМ на рабочем столе → Создать → Ярлык.

4. В поле «Расположение» вставьте (одной строкой):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --user-data-dir="%LOCALAPPDATA%\FulfillmentCRM-Print" --disable-extensions --kiosk-printing --new-window http://5.129.243.246:8080/?print_mode=kiosk

   Если Chrome не в Program Files — укажите свой путь к chrome.exe.

5. Имя ярлыка: Fulfillment CRM (autoprint)

6. Открывайте CRM ТОЛЬКО через этот ярлык.

Проверка:
- Одна вкладка Fulfillment CRM (не github, не WB).
- Справа нет иконок расширений.
- После скана стикера НЕТ окна «Печать» с кнопкой — сразу на Xprinter.

Актуальный URL — на странице CRM «Агент печати».
