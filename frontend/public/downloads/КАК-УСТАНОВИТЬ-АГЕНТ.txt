Fulfillment CRM — установка агента печати
======================================

СЕРВЕР (скопируйте в консоль Timeweb, один раз):

cd /opt/fulfillment-crm && git pull && bash scripts/deploy.sh


ПК СКЛАДА:

1. CRM → Агент печати → «Скачать и установить (1 файл)»
2. Дважды щёлкните Установить-агент-печати.bat
3. Дождитесь «ГОТОВО»

Xprinter — принтер по умолчанию в Windows.
