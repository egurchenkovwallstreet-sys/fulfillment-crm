## ТЕКУЩАЯ ЗАДАЧА

**Скан vs лента + лист подбора:** разделены. На «Новые» и «На сборке» кнопка **«Сформировать лист подбора»** по выбранному складу, затем **«Скачать PDF»**. Лента печатается через агент (PNG по очереди), Chrome — запас. **Проверить на проде** после деплоя.

Окно ЧЗ после скана: тоже проверить («На сборке» → «Скан» → баркод с ЧЗ → жёлтое окно должно остаться).

Если снова сброс ЧЗ — не повторять патчи `7182ed6`…`a98af0b`; см. `тз и прогрес/2026-08-30-сборка-fbs-окно-чз.md`.
