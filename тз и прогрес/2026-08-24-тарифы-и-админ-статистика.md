# Тарифы, суммы отгрузок и админ-статистика

**Дата:** 24.08.2026  
**Статус:** ✅ Реализовано  
**Коммиты:** `4d5e4e4` … `7d33a0f`

---

## Задачи сессии

1. Админ назначает тариф селлеру (на все товары или на ценовую группу).
2. В кабинете селлера — суммы отгрузок по тарифу (неделя / дни).
3. Учитывать **все** отгруженные на WB заказы, не только прошедшие через CRM.
4. Админу — сводная статистика по всем клиентам + итого.

---

## 1. Тарифы (админ → Селлеры)

| Элемент | Описание |
|---------|----------|
| UI | `/sellers` → колонка **«Тариф»** → модальное окно |
| Режим «На все товары» | `individual_price` на все SKU селлера |
| Режим «На ценовую группу» | тариф на товары группы; чекбокс «назначить группу товарам без группы» |
| API | `GET/POST /api/warehouse/sellers/<id>/pricing/`, `GET /api/warehouse/price-groups/` |
| Backend | `warehouse/services/seller_pricing.py`, `warehouse/views_pricing.py` |

Ценовые группы (`PriceGroup`) — в Django-admin.

---

## 2. Суммы в кабинете селлера

- Блок «Отгрузки на склад WB»: **итого за неделю в ₽** + заказов; по дням — заказы и сумма.
- Расчёт: заказ × тариф товара (`Product.processing_price`); если баркод неизвестен — общий тариф селлера (если единый `individual_price` у всех товаров).
- Коммит: `dbcfc6c`

---

## 3. Все отгрузки WB (не только CRM)

**Было:** считались только заказы из таблицы `Order` в CRM.  
**Стало:**
- ID заказов — из WB API (`GET .../supplies/{id}/order-ids`) для каждой поставки `done`.
- Баркод/склад — индекс CRM + архив WB за 30 дней.
- Фильтр включённых FBS-складов сохранён.
- Заказы без записи в CRM **включаются** в отгрузки.

Коммит: `c75a9b7`

---

## 4. Админ-статистика `/billing`

| Элемент | Описание |
|---------|----------|
| Маршрут | `/billing` (меню **«Статистика»**, только admin) |
| API | `GET /api/sellers/admin/billing/` |
| Блок 1 | **Все селлеры — итого:** график 4 недели (заказы + ₽) |
| Блок 2 | **Таблица по селлерам:** заказов, сумма, поставок за выбранную неделю |
| Backend | `merge_weekly_shipments_payloads()`, `load_admin_billing_dashboard()` |

Первая загрузка: 1–2 мин (запросы WB по каждому селлеру).

Коммит: `7d33a0f`

## Ограничения

- Statistics API: лимит 1 req/min, данные до 90 дней.
- Отгрузки: до 300 запросов order-ids за загрузку (`MAX_SUPPLY_ORDER_FETCHES`).
- Тариф по баркоду — если товар не в CRM и нет в архиве WB, сумма идёт по общему тарифу селлера.
