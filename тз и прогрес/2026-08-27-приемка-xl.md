**Дата:** 27.08.2026  
**Статус:** ✅ Реализовано, готово к деплою  
**Решение по возвратам:** отдельный модуль §11 **не делаем** — товар принимается как новая партия.

---

## Задача

Новый клиент фулфилмента, токен WB ещё не подключён. Нужно пересчитать товар сканером поштучно, сохранить список и выгрузить Excel. После API — полноценный клиент с ячейками и фото. Остатки в ЛК WB не трогаем (будет отдельная кнопка).

---

## Экран сканирования

| Элемент | Как работает |
|---------|----------------|
| Строка баркода | Крупная, **всегда в фокусе**. Только сканер, без клавиш ноутбука |
| Плитка слева (синяя) | Порядковый номер **уникального** баркода (1, 2, 3…). Повтор того же баркода — тот же номер |
| Плитка справа (зелёная) | Сколько штук **этого** баркода уже пробили |
| Счётчик сверху | Всего единиц + число уникальных баркодов (не крупный) |
| Список ниже | Все баркоды и количества |
| Сохранить | Фиксирует сессию, можно скачать Excel |

Excel: два столбца — **Баркод**, **Количество**.

---

## После API WB

1. Вставка персонального токена на сохранённой сессии (или токен уже есть).
2. CRM тянет карточки Content API (название, фото, размер, needKiz).
3. Совпавшие баркоды получают ячейки **по порядку размеров** внутри артикула.
4. Остатки на склад WB **не отправляются**.
5. Баркоды, которых нет в ЛК — **отдельное окно**, ячейки не создаются.

## Меню и API

## Проверка после деплоя

1. `cd /opt/fulfillment-crm && git pull && bash scripts/deploy.sh`

5. Вставить токен WB → ячейки и фото; ненайденные баркоды в окне
