## Задача

Новый клиент фулфилмента, токен WB ещё не подключён. Нужно пересчитать товар сканером поштучно, сохранить список и выгрузить Excel. После API — полноценный клиент с ячейками и фото. Остатки в ЛК WB не трогаем (будет отдельная кнопка).

---

## Экран сканирования

| Элемент | Как работает |
|---------|----------------|
| Строка баркода | Крупная, **всегда в фокусе** (пока приёмка не завершена). Только сканер, без клавиш ноутбука |
| Плитка слева (синяя) | Порядковый номер **уникального** баркода (1, 2, 3…). Повтор того же баркода — тот же номер |
| Плитка справа (зелёная) | Сколько штук **этого** баркода уже пробили |
| Счётчик сверху | Всего единиц + число уникальных баркодов (не крупный) |
| Список ниже | Все баркоды и количества |
| Подсказка | «Каждый скан сохраняется автоматически» — данные в БД сразу, F5 не теряет прогресс |

Excel: два столбца — **Баркод**, **Количество**. Скачать можно в любой момент, когда есть хотя бы одна строка.

## Жизненный цикл сессии (29.08.2026)

| Статус | Значение | Сканирование | Действия |
|--------|----------|--------------|----------|
| `scanning` | Идёт скан | ✅ | Сохранить, Excel, WB, Завершить |
| `saved` | Контрольная точка | ✅ | Сохранить снова, Excel, WB, Завершить |
| `applied` | Ячейки созданы в CRM | ✅ | Скан новых единиц → повторный WB (дельта), Сохранить, Excel, Завершить |
| `completed` | Приёмка закрыта | ❌ | Только просмотр списка и Excel |

### Кнопки

| Кнопка | Поведение |
|--------|-----------|
| **Сохранить** | Контрольная точка (`saved_at`). **Не блокирует** сканирование. Доступна на этапах `scanning`, `saved`, `applied` |
| **Скачать Excel** | В любой момент при наличии строк (не требует «Сохранить») |
| **Создать / применить ячейки WB** | Подтягивает каталог, создаёт ячейки. После `applied` можно вызвать **повторно** — в CRM уходит только **дельта** (`quantity − applied_quantity` на строке) |
| **Завершить приёмку** | Финальное закрытие → `completed`. Сканирование и изменения навсегда закрыты (подтверждение в UI) |

### Повторное применение WB

- На модели `XlIntakeLine` поле **`applied_quantity`** — сколько штук уже учтено в CRM.
- При повторном `connect-wb` остаток увеличивается только на новые сканы; двойного списания нет.
- Миграция `0007_xl_intake_resume.py` выставляет `applied_quantity = quantity` для уже применённых сессий.

## После API WB

1. Вставка персонального токена на сессии (или токен уже есть у клиента).
2. CRM тянет карточки Content API (название, фото, размер, needKiz).
3. Совпавшие баркоды получают ячейки **по порядку размеров** внутри артикула.
4. Остатки на склад WB **не отправляются**.
5. Баркоды, которых нет в ЛК — **отдельное окно**, ячейки не создаются.
6. После создания ячеек можно **продолжить сканирование** и снова нажать «Применить новые баркоды».

## Меню и API

- UI: `/intake-xl`, `/intake-xl/:id`
- `GET/POST /api/warehouse/xl-intake/sessions/` — список / новая сессия
- `GET /api/warehouse/xl-intake/sessions/<id>/` — детали
- `POST .../scan/` — скан одной единицы (если не `completed`)
- `POST .../save/` — контрольная точка
- `GET .../excel/` — Excel
- `POST .../connect-wb/` — токен WB → карточки, ячейки, окно «не найдено»
- `POST .../complete/` — **завершить приёмку** (новое 29.08.2026)

**Файлы:**
- `backend/apps/warehouse/models.py` — `XlIntakeSession`, `XlIntakeLine` (+ `completed`, `applied_quantity`)
- `backend/apps/warehouse/services/xl_intake.py`
- `backend/apps/warehouse/views_xl_intake.py`
- `backend/apps/warehouse/migrations/0007_xl_intake_resume.py`
- `frontend/src/pages/XlIntakePage.tsx`, `frontend/src/api/xlIntake.ts`

## Проверка после деплоя

1. `cd /opt/fulfillment-crm && git pull && bash scripts/deploy.sh`
2. Ctrl+F5
3. Меню → **Приёмка в XL** → название ИП → сканер бьёт единицы
4. F5 — данные на месте (автосохранение скана)
5. **Сохранить** → продолжить скан → Excel
6. Токен WB → ячейки; ненайденные баркоды в окне
7. После ячеек — ещё несколько сканов → **Применить новые баркоды** → дельта в CRM
8. **Завершить приёмку** → сканирование закрыто, в списке статус «Завершена»
9. В ЛК WB остатки не должны измениться
