## Контекст

**Система 1 (как сейчас):** ₽/шт — не ломаем.

**Система 2 (литраж):** габариты → литры → ежедневное хранение + ступенчатая отгрузка.

Режим включается **на селлера**: `Seller.pricing_mode = per_unit | per_liter`.

**Ozon** — те же правила, что WB.

## Согласованные ответы (06.09.2026)

| # | Вопрос | Ответ |
|---|--------|--------|
| 1 | Период хранения | **Каждый день** от кол-ва шт на складе по баркоду. После перехода заказа **в доставку** остаток уменьшается → хранение на меньшее кол-во |
| 2 | Габариты | **Один раз на баркод** (см). При приёмке — окно «проверьте габариты», можно изменить |
| 3 | Уровень системы 2 | **На селлера** |
| 4 | Ozon | **Те же правила** |
| 5 | Округление объёма | **Вверх до 0,1 л** |

Дополнительно для **отгрузки** (литры сверх первого):

- **1-й литр** — отдельная ставка.
- **Сверх 1 л** — «хвост» округляем **вверх**:
  - если ≤ **0,5 л** → платим за **0,5 л**;
  - если **> 0,5 л** → округляем **до целого литра вверх**.
- Далее умножаем округлённый хвост на ставку «за литр сверх первого».

## Стартовые тарифы (дефолты, владелец может менять)

| Параметр | Значение |
|----------|----------|
| 1-й литр отгрузки (обработка + отправка) | **10 ₽** |
| Каждый литр сверх первого (после округления хвоста) | **6 ₽** |
| Надбавка за Честный знак | **+5 ₽ / шт** (за скан ЧЗ) |
| Хранение | **1 ₽ / литр / месяц** |

Владелец фулфилмента (`/owner`) редактирует все ставки.

---

## Расчёт объёма (калькулятор габаритов)

```
raw_liters = (length_cm × width_cm × height_cm) / 1000
volume_liters = ceil(raw_liters, 0.1)   // вверх до 0,1 л
```

Поля на `Product`: `length_cm`, `width_cm`, `height_cm`, `volume_liters` (кэш).

---

## Хранение (ежедневно)

За **каждый баркод**, за **каждый день**:

```
daily_storage_₽ = qty_on_shelf × volume_liters × (storage_tariff_monthly / days_in_month)
```

- `qty_on_shelf` — штуки в ячейках CRM на конец дня (после списаний при переходе в доставку).
- `storage_tariff_monthly` — ₽/л/мес (старт **1 ₽**, редактирует владелец).

**Пример:** 100 шт × 0,5 л × (1/30) ≈ 1,67 ₽/день; после отгрузки 15 шт → 85 шт × …

## Отгрузка (за заказ, при переходе в доставку)

```
function shipment_cost(volume_liters, has_marking):
  first = min(volume_liters, 1)
  extra = max(volume_liters - 1, 0)
  if extra == 0:
    extra_billed = 0
  elif extra <= 0.5:
    extra_billed = 0.5
  else:
    extra_billed = ceil(extra)   // целые литры вверх

  cost = first_liter_tariff                    // 10 ₽ если first > 0
  if extra_billed > 0:
    cost += extra_billed * next_liter_tariff   // × 6 ₽
  if has_marking:
    cost += marking_surcharge_per_unit         // +5 ₽
  return cost
```

**Примеры без ЧЗ (10 + 6×хвост):**

| Объём | Расчёт | Итого |
|-------|--------|-------|
| 0,8 л | 1-й л | 10 ₽ |
| 1,2 л | 10 + 0,5×6 | 13 ₽ |
| 1,6 л | 10 + 1×6 | 16 ₽ |
| 2,3 л | 10 + 2×6 (1,3 → 2 л) | 22 ₽ |

**С ЧЗ:** +5 ₽ к сумме.

## Модель данных (черновик)

- `Seller.pricing_mode`: `per_unit` | `per_liter`
- `Seller` (или `FulfillmentLiterTariff`): `first_liter_shipment_price`, `next_liter_shipment_price`, `marking_surcharge_per_unit`, `storage_tariff_per_liter_month`
- `Product`: габариты см, `volume_liters`, `requires_marking` (или из lookup)
- `DailyStorageCharge` (или аналог): дата, seller, barcode, qty, liters, amount
- `ShipmentCharge`: дата, order, barcode, volume, amount, marking_surcharge

## UI — реализация

### Приёмка `/intake`
- Селлер на `per_liter` → после скана баркода поля Д×Ш×В (см) или напоминание проверить.
- Калькулятор: сразу показывает литры (0,1 вверх).

### Владелец `/owner`
- Редактирование тарифов литража (4 поля + режим селлера).
- `/owner/billing` — те же графики, что у селлера, по всем клиентам.

### Кабинет селлера `/cabinet` — **2 блока с инфографикой**

Только для селлеров с `pricing_mode = per_liter`. Система 1 — без изменений.

#### Блок 1 — **Хранение**
- **График** (столбцы/линия): начисления по дням за выбранный период (неделя / месяц).
- **Инфографика** (кратко на экране):
  - «Сколько штук лежит → × литры → × тариф в месяц ÷ дни»
  - Пример: «100 шт × 0,5 л × 1 ₽/мес ÷ 30 ≈ …/день»
- **Таблица** по баркодам: шт на складе, л/шт, литро-дни, ₽ за период.
- Переключатель периода (как у графика отгрузок — 4 недели).

#### Блок 2 — **Отгрузки**
- **График**: заказы и **₽ по новой формуле** (не ₽/шт) по дням.
- **Инфографика**:
  - 1-й литр — X ₽, дальше — Y ₽/л (с округлением хвоста 0,5 / целый)
  - +5 ₽ если был ЧЗ
  - Мини-пример на 1,2 л и 2,3 л
- **Таблица** по дням/заказам: баркод, литры, ЧЗ да/нет, ₽.

Размещение: под текущими карточками заказов / над таблицей остатков (или отдельная вкладка «Финансы», если не помещается).
