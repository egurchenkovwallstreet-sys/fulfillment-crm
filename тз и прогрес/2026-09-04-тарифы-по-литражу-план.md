# Тарифы по литражу — план (система 2)

**Дата:** 04.09.2026  
**Статус:** 📋 Запланировано (не реализовано)  
**Приоритет:** следующая крупная задача после сборки FBS

---

## Контекст

Сейчас (**система 1**) тариф один — **₽ за штуку** (обработка/отгрузка):
- Админ назначает тариф селлеру: на все товары или на ценовую группу.
- Кабинет селлера и `/owner/billing` считают: **заказы × тариф за штуку**.

Нужна **вторая система тарифов (система 2)** — расчёт по **объёму товара в литрах**.

---

## Две системы тарифов (выбор на селлера или при приёмке)

| | Система 1 (как сейчас) | Система 2 (литраж) |
|---|------------------------|---------------------|
| Единица | ₽ / штука | ₽ / литр (хранение) + ₽ / литр (отгрузка) |
| Данные | Только баркод + количество | **Габариты** товара (Д×Ш×В см) → CRM считает литры |
| При приёмке | Без габаритов | Менеджер вводит габариты (или выбирает «система 1») |
| Хранение | Не считается по литрам | Стоимость хранения **по каждому баркоду × количество × литры × тариф хранения** |
| Отгрузка | Заказ × тариф шт. | Заказ × **литраж SKU** × тариф отгрузки |

## Требования (согласовано 04.09.2026)

### 1. Выбор системы при приёмке
- На экране приёмки менеджер выбирает: **«Тариф по штукам»** или **«Тариф по литражу»**.
- Если выбрана **система 2** — после скана баркода (или в карточке товара) можно указать **габариты** (длина, ширина, высота в см).
- CRM **сама считает объём в литрах**: `литры = (Д × Ш × В) / 1000` (округление — уточнить при реализации).

### 2. Два тарифа для системы 2
- **Тариф хранения** (₽/литр/… — период уточнить: день? месяц?).
- **Тариф отгрузки** (₽/литр за единицу отгруженного товара).

Назначение тарифов — **админ** (кабинет владельца `/owner`), аналогично текущим тарифам по штукам.

### 3. Расчёты для селлера и админа
- **Селлер** (`/cabinet`): суммы хранения и отгрузок с разбивкой по баркодам (литры × тариф).
- **Админ** (`/owner/billing`): те же расчёты по всем селлерам + итого.
- Селлеры на **системе 1** — без изменений (обратная совместимость).

### 4. Модель данных (черновик)
- `Seller.pricing_mode`: `per_unit` | `per_liter` (или на уровне приёмки/товара).
- `Product`: поля `length_cm`, `width_cm`, `height_cm`, `volume_liters` (вычисляемое/кэш).
- `Seller` или отдельная таблица: `storage_tariff_per_liter`, `shipment_tariff_per_liter`.

### 5. UI (черновик)
- Приёмка `/intake`: переключатель системы + поля габаритов при системе 2.
- `/owner/sellers` → тариф: режим «по штукам» / «по литражу» + два поля тарифа.
- Кабинет и billing: колонки «литры», «хранение ₽», «отгрузка ₽».
