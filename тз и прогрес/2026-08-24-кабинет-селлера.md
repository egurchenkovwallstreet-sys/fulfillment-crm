## Задача

Селлер (ИП Мазирка) видел в кабинете **37 заказов за месяц** — столько же, сколько «Новых» в сборке. В сводном отчёте WB за август — **~2627 заказов** (90–160 в день, FBS). Нужны корректные счётчики, стадии WB, отгрузки на склад WB и сравнение с прошлым периодом.

---

## Что сделано

### 1. Карточки заказов (день / неделя / месяц)

- Календарные периоды в **Europe/Moscow** (как в отчётах WB):
  - **Сегодня** — календарный день
  - **Неделя** — пн–вс
  - **Месяц** — с 1-го числа
- Сравнение с предыдущим периодом: стрелки и % (к вчера / к прошлой неделе / к прошлому месяцу)

### 2. Карточки стадий WB

- **Новые / На сборке / В доставке** — те же числа, что в разделе «Сборка FBS» (`get_seller_wb_tab_counts`)

### 3. Переход на WB Statistics API

| Было (неверно) | Стало (верно) |
|----------------|---------------|
| Marketplace API: `/api/v3/orders/new` + `/api/v3/orders` | Statistics API: `GET /api/v1/supplier/orders` |
| ~37 активных заданий на сборку | Уникальные заказы по `srid`, как «Количество заказов» в сводном отчёте |
| База: `marketplace-api.wildberries.ru` | База: `statistics-api.wildberries.ru` |

**Фильтры:**
- `warehouseType` = «Склад продавца» (FBS)
- `isCancel` = false
- Уникальный заказ — поле `srid`

**Токен WB:** обязательна категория **«Статистика»**.

**Файлы:**
- `backend/apps/integrations/wb_statistics_client.py` — клиент Statistics API
- `backend/apps/sellers/services/wb_order_stats.py` — агрегация по периодам
- `backend/apps/sellers/services/calendar_periods.py` — календарь МСК
- `backend/config/settings.py` — `WB_STATISTICS_API_BASE_URL`

### 4. Отгрузки на склад WB

- Источник: `GET /api/v3/supplies`, `done=true`, дата `scanDt` / `closedAt`
- Считаются заказы из поставок, переданных/отсканированных WB
- **Интерактивный блок:** последние **4 календарные недели**
  - вкладки по неделям («Текущая», диапазон дат)
  - стрелки ← →
  - столбчатый график по дням (пн–вс)

**Файлы:**
- `backend/apps/sellers/services/seller_billing_stats.py`
- `frontend/src/pages/SellerCabinetPage.tsx`

### 5. Таблица «Товары и остатки»

- Остатки на фулфилменте
- Заказы д/н/м по штрихкоду
- Средние продажи за 7 дней, «хватит на N дней»
- Статус запаса: Догрузить / Норма / Много

## Ограничения / риски

1. **Statistics API:** лимит 1 запрос/мин, данные обновляются ~раз в 30 мин, хранение до 90 дней.
2. **Отгрузки:** при отсутствии поставки в CRM — разбор имени `CRM-{orderId}-*` или запрос order-ids у WB (до 80 поставок за загрузку).
3. **Счётчики стадий** (Новые/Сборка/Доставка) и **история заказов** (день/неделя/месяц) — разные источники API; это ожидаемо.
